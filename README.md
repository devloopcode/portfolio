# Mohamed Idbenouakrim - Personal Portfolio

A minimal, high-performance personal portfolio built with [Next.js](https://nextjs.org/) (App Router), React, and Tailwind CSS.

## 🚀 Features

- **Modern Stack:** Next.js 16+ (App Router), React 19, Tailwind CSS v4
- **Performance:** Highly optimized, fast loading, and fully responsive
- **Design:** Custom minimalist design with a focus on typography and subtle animations
- **SEO Ready:** Fully optimized for search engines with proper metadata and sitemaps

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Deployment:** [Vercel](https://vercel.com/)
- **Typography:** [Geist Font](https://vercel.com/font)

## 💻 Getting Started

First, clone the repository and install the dependencies:

```bash
git clone git@github.com:devloopcode/portfolio.git
cd portfolio
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🚢 Deployment

The easiest way to deploy this project is to use the [Vercel Platform](https://vercel.com/new).

> **Important Setup Note before going live:**  
> Remember to replace `https://idbenouakrim.dev` in `app/layout.tsx`, `app/robots.ts`, and `app/sitemap.ts` with your actual domain name to ensure SEO and sharing links work correctly.
